# 2025-2026 安全员 C3 答题系统

建筑施工安全员（C3）资格考试题库，单文件纯静态网页，无需服务器，支持 iPad / 移动端。

## 功能概览

### 三种答题模式

| 模式 | 说明 |
|------|------|
| **即时** | 选完即时显示对错与AI解析，跟踪答对数与错题数 |
| **考试** | 模拟真实考试，计时（当前题 + 总用时），交卷后显示汇总 |
| **看题** | 自动倒计时显示答案（3 / 5 / 10 秒可选），答案揭晓后自动翻下一题 |

### 看题模式细节
- **延迟显示**：导航到题目后开始倒计时，时间到自动标注正确答案并展开解析
- **自动翻题**：显示答案后等待 2× 延迟时间再跳下一题（如延迟 3s → 答案显示 6s 后翻题）
- **语音联动**：若开启"自动播报"，则播完语音后再翻题，而非按计时器翻题
- **手动优先**：用户主动点选选项，立即取消倒计时和自动翻题

### 跳题逻辑
- **即时模式**：跳已答 / 跳未答两个开关，互斥（不能同时开启）；跳已答默认开启
- **考试模式**：跳已答默认开启，聚焦未做题目
- **看题模式**：跳已答可手动开关

### 滑动导航（iPad / 移动端）
- 左右滑动切换题目，预加载前后题目内容
- 垂直滚动正常工作，不与滑动冲突
- 阈值 60px，低于阈值自动复位

### 其他功能
- AI 解析：记忆口诀、速记、核心考点、选项逐项分析
- 收藏夹（⭐）、错题集（✗）、题号跳转
- 重答模式：点击题号可清除答题记录重新作答
- 语音播报（Web Speech API）：自动播报 / 手动播放 / 语速调节
- 三套主题：暗夜 / 奶油 / 暗夜绿
- 字号调节（13–22px）
- 本地数据导出 / 导入（JSON）
- 云端同步（需配套 `save_progress.php`）

## 使用方法

1. 克隆或下载仓库
2. 用浏览器直接打开 `quiz/Index.html`（或部署到任意静态服务器）
3. 选择题库 → 开始答题

> 云端同步功能需要服务器端 `save_progress.php`，纯本地使用可忽略。

## 键盘快捷键

| 按键 | 功能 |
|------|------|
| `←` / `→` | 上一题 / 下一题 |
| `A` – `E` | 选择对应选项 |
| `V` | 立即播放当前题语音 |
